# WinNetTool
A Windows WinForms utility for fast network troubleshooting, DNS management, and system configuration.

## Features
- Flush DNS & Network Reset
- Disable Proxy & LAN Settings
- Execute Windows Run commands automatically
- Set/Remove custom DNS
- Display System IP info

## Technologies
- C# (.NET Framework 4.7.2)
- Windows Forms

# وین‌نت‌تول (WinNetTool)
یک ابزار کاربردی ویندوز (WinForms) برای رفع سریع مشکلات شبکه، مدیریت دی‌ان‌اس و پیکربندی سیستم.

## امکانات
- فلاش دی‌ان‌اس و ریست شبکه
- غیرفعال‌سازی پروکسی و تنظیمات LAN
- اجرای خودکار دستورات Run ویندوز
- تنظیم و حذف DNS دلخواه
- نمایش اطلاعات آی‌پی سیستم

## تکنولوژی‌ها
- سی‌شارپ (دات‌نت فریم‌ورک 4.7.2)
- ویندوز فرم (WinForms)
